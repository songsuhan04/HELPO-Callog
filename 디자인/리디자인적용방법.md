## 1. 적용하기 (당시 절차 — 기록용)

리포 최상위에서:

```bash
git checkout -b redesign/alarmy-style
git apply callogredesign.patch
```

`git apply`는 파일만 바꾸고 커밋은 하지 않습니다. 커밋 이력까지 그대로 가져오려면:

```bash
git checkout -b redesign/alarmy-style
git am callogredesign.patch
```

## 2. 실행하기

```bash
cd demo/v1
npm install
npm run dev
```

`.env.local`에 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`가 있어야 로그인과 데이터 조회가 됩니다.
(없으면 화면은 다 보이지만 입력칸이 잠깁니다 — 기존 `supabaseConfigured` 동작 그대로입니다.)

## 3. 되돌리기

```bash
git checkout main
git branch -D redesign/alarmy-style
```

## 무엇이 바뀌었나

### 색과 글꼴

`src/styles/theme.css`의 토큰을 전부 교체했습니다. 색값은 눈대중이 아니라
알라미 스크린샷 5장의 픽셀을 집계해 뽑은 실제 값입니다.

| 역할 | 값 |
|---|---|
| 배경 | `#121416` |
| 카드 | `#1E1F25` |
| 주요 버튼 | `#404ED7` |
| 강조 · 경고 | `#FC314D` |
| 게이지 · 차트 | `#14A8CD` |

예전 토큰 이름(`--dawn`, `--mist`, `--ink2` …)은 지우지 않고 새 값으로 다시 이어뒀습니다.
아직 그 이름을 쓰는 코드가 있어도 깨지지 않습니다.

### 넓은 화면에서의 레이아웃

화면마다 하는 일이 달라서 다르게 폅니다.

- **어르신 화면** — 폰 비율을 유지한 채 액자에 넣고, 폭 대신 글자와 버튼을 키웁니다(`--e-zoom`).
  버튼 하나에 할 일 하나라 넓혀도 채울 것이 없고, PC에서도 스마트폰과 같은 자리에 같은 것이
  있어야 자녀분이 전화로 "가운데 파란 버튼 누르세요"라고 설명할 수 있습니다.
- **보호자 화면** — 사이드바 + 요약 타일 + 2단 카드로 모니터 폭을 씁니다.
  대상자 목록·상세·관리자 화면이 해당합니다.
- **폼 화면**(가입·어르신 등록·지병 선택) — 가운데 좁은 카드 그대로입니다.
  입력 폼은 넓힐수록 읽기 어려워집니다.

### 어르신 화면 설정 (새로 추가)

어르신이 **바탕 4종 × 글씨 3단계**를 직접 눌러보고 고릅니다. 고른 값은
`localStorage`에 저장되고, 어르신 화면 7곳 어디서든 `가+ 화면 설정`으로 열 수 있습니다.

바탕을 여러 개 둔 이유는 잘 보이는 화면이 사람마다 다르기 때문입니다.
백내장이 있으면 어두운 배경의 흰 글씨가 번져 보이고, 노안만 있으면 크기만 키우면 됩니다.

| 바탕 | 쓰임 |
|---|---|
| 밤하늘 (기본) | 알라미 톤 |
| 한낮 | 다크에서 글자가 번져 보이는 경우 |
| 노을 | 청색광이 부담스럽거나 잠들기 전 사용이 잦은 경우 |
| 또렷하게 | 저시력용 검정+노랑 고대비 |

글씨 배율 `1 / 1.15 / 1.3`은 기존 `FontSizeToggle`의 값을 그대로 씁니다.

### 새 파일 2개

- `src/lib/elderDisplay.ts` — 고른 설정 저장·복원
- `src/components/DisplaySettings.tsx` — 고르는 시트

`src/components/FontSizeToggle.tsx`는 삭제했습니다. 글씨 크기만 순환시키는 방식이라
지금 몇 단계인지 알 수 없고 되돌리려면 끝까지 눌러야 해서, 고른 것이 보이는 방식으로 바꿨습니다.

## 작업 중 발견해 함께 고친 것

리디자인과 별개로, 보다가 발견한 것들입니다. 문제가 되면 해당 부분만 빼셔도 됩니다.

1. **`Pretendard` 폰트가 로드된 적이 없었습니다.** `theme.css`가 찾기만 하고
   `index.html` 어디서도 불러오지 않아 조용히 맑은고딕으로 떨어지고 있었습니다.
   알라미 톤에 가까운 **Gothic A1**을 Google Fonts에서 실제로 불러오도록 했습니다.
2. **한글이 단어 중간에서 끊겼습니다.** "전해볼까요" → "전 / 해볼까요".
   `word-break: keep-all`로 어절 단위 줄바꿈으로 바꿨습니다.
3. **`<html lang="en">`** 이었습니다. 한국어 서비스인데 스크린리더가 영어로 읽습니다. `ko`로 고쳤습니다.

## 아직 안 한 것 — 팀 논의가 필요합니다

1. **어르신 첫 진입 시 바탕 고르는 화면**을 따로 둘지.
   화면이 하나 늘어나므로 라우트 추가가 필요합니다. 지금은 아무 때나 열 수 있게만 해뒀습니다.
2. **보호자 목록↔상세를 한 화면에 나란히** 놓을지.
   목록과 상세가 별도 라우트라 라우팅 변경이 필요해서 손대지 않았습니다.
   대신 각 화면 안에서 2단으로 나눠 폭을 쓰게 했습니다.
