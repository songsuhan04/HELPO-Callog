# 체험 설문지 (2026-11-02)

지인 배포분 회수용. 구글폼 두 개로 나눈다.

**왜 둘로 나누는가.** 콜록은 쓰는 사람이 둘이다. 어르신은 매일 답하고, 보호자는
등록하고 알림을 받는다. 두 사람이 겪는 것이 완전히 다르므로 한 장으로 받으면
양쪽 다 흐려진다.

**설계 원칙 — 만족이 아니라 행동을 묻는다.** "좋으셨어요?"에는 거의 다 "좋았다"가
온다. 특히 어르신은 부탁한 자녀를 배려하신다. 그래서 "며칠 안 하셨고 왜 안 하셨는지",
"알림 받고 무엇을 하셨는지"처럼 일어난 일을 묻는다.

---

## 폼 1 — 어르신용

### 폼 제목
```
콜록, 어떠셨어요?
```

### 설명문
```
콜록을 만든 학생들입니다. 여섯 가지만 여쭤볼게요. 2분이면 됩니다.

불편하셨던 점을 그대로 적어주셔야 저희가 고칩니다.
좋게 써주지 않으셔도 괜찮습니다.
```

### 문항

**1. 매일 뜨는 질문에 답하시는 거, 번거로우셨어요?** `객관식`
- 전혀 번거롭지 않았다
- 조금 번거로웠다
- 많이 번거로웠다

**2. 질문이 무슨 말인지 바로 아시겠던가요?** `객관식`
- 다 알아들었다
- 가끔 헷갈렸다
- 자주 헷갈렸다

**3. 답을 안 하신 날이 있으셨어요? 있었다면 왜 그러셨어요?** `객관식` ← 가장 중요
- 안 한 날 없다
- 깜빡 잊어서
- 어디서 하는지 못 찾아서
- 귀찮아서
- 몸이 안 좋아서
- 기타

**4. 글씨 크기는 어떠셨어요?** `객관식`
- 잘 보였다
- 작아서 불편했다
- 키우는 방법을 몰랐다

**5. 질문을 소리로 읽어주는 기능이 있는 건 아셨어요?** `객관식`
- 알았고 써봤다
- 알았지만 안 썼다
- 몰랐다

**6. 다음 주에도 계속 하시겠어요?** `객관식`
- 계속하고 싶다
- 안 해도 괜찮다
- 잘 모르겠다

**7. 불편하셨던 점이나 하고 싶은 말씀** `주관식 · 선택`

### 구글폼 설정 — 어르신용은 여기가 중요하다
- **모든 문항 "필수" 끄기.** 한 문항에서 막히면 제출 자체를 못 하신다.
- **"로그인 필요" 끄기.** 켜두면 구글 계정 로그인 화면부터 만나신다.
- 이메일 주소 수집 끄기
- 진행률 표시줄 켜기 — 끝이 보여야 끝까지 가신다
- 질문 순서 섞기 끄기

### 전달
보호자가 어르신께 링크를 전달한다. 어르신이 폼을 못 여시면 **전화로 대신 받아적는다**
— 문항은 그대로 읽으면 된다.

## 폼 2 — 보호자용

### 폼 제목
```
콜록 써보신 후기 (가족용)
```

### 설명문
```
링크 보내드렸던 콜록입니다. 5분이면 됩니다.

솔직하게 적어주실수록 도움이 됩니다.
"별로였다", "안 써봤다"도 저희에겐 중요한 답입니다.
```

### 문항

**1. 어르신은 어떻게 지내세요?** `객관식 · 필수`
- 혼자 사신다
- 어르신 두 분이 사신다
- 저와 떨어져 다른 가족과 사신다
- 저와 함께 산다

**2. 어르신이 실제로 답을 하셨나요?** `객관식 · 필수` ← 분기의 핵심
- 매일 또는 거의 매일 하셨다
- 처음 며칠만 하셨다
- 한두 번만 하셨다
- 한 번도 안 하셨다
- 링크를 아직 안 보냈다

**3. "며칠만" 또는 "안 하셨다"고 답하셨다면 — 어디서 멈추신 것 같나요?** `주관식 · 선택`
> 링크를 안 누르셨는지, 누르셨는데 어려워하셨는지, 모르시겠는지

**4. 어르신 등록(이름·연락처 입력)은 어떠셨나요?** `객관식 · 필수`
- 쉬웠다 / 보통이었다 / 어려웠다 / 끝까지 못 했다

**5. 홈 화면에 설치하셨나요?** `객관식 · 필수`
- 아이폰 · 설치함 / 아이폰 · 안 함
- 안드로이드 · 설치함 / 안드로이드 · 안 함
- 모르겠다

**6. 알림을 받아보셨나요?** `객관식 · 필수`
- 받았다 / 켰는데 안 왔다 / 켜는 방법을 몰랐다 / 켜지 않았다

**7. 알림을 받으셨다면, 받고 무엇을 하셨나요?** `주관식 · 선택` ← 행동 데이터
> 전화를 거셨는지, 그냥 넘기셨는지, 직접 가보셨는지

**8. 쓰시면서 막히거나 헷갈린 곳이 있었나요?** `주관식 · 필수`
> 없으면 "없음"이라고 적어주세요

**9. 지금은 어르신 안부를 어떻게 확인하세요?** `객관식 · 필수`
- 매일 전화 / 가끔 전화 / 카톡·문자 / 거의 못 한다 / 함께 산다 / 기타

**10. 내일부터 콜록을 더 못 쓰게 된다면 어떠실 것 같나요?** `객관식 · 필수`
- 매우 아쉽다 / 조금 아쉽다 / 별로 아쉽지 않다

**11. 둘 중 하나에만 돈을 낼 수 있다면 어느 쪽인가요?** `객관식 · 필수` ← 멘토 요청 문항
- 안부 확인을 자주 해주는 것
- 영상편지를 오래 보관해주는 것
- 둘 다 내지 않겠다

**12. 11번을 그렇게 고르신 이유는?** `주관식 · 필수`

**13. 더 하고 싶은 말씀** `주관식 · 선택`

**14. 더 자세히 얘기 나눠주실 수 있다면 연락처** `주관식 · 선택`
> 빈칸으로 두셔도 됩니다

### 구글폼 설정
- "로그인 필요" 끄기
- 이메일 주소 수집 끄기
- 진행률 표시줄 켜기

## 읽는 법

- **폼2 10번**이 PMF 신호다. "매우 아쉽다"가 40%를 넘으면 쓸 만한 것을 만든 것이고,
  밑돌면 아직 아니다.
- **폼2 2번과 폼1 3번을 겹쳐 본다.** 보호자는 "며칠만 하셨다"고 보고, 어르신은
  "못 찾아서"라고 답하면 원인은 제품이 아니라 진입 경로다.
- **"며칠 하셨어요"는 묻지 않았다.** DB에 이미 있다. 기억보다 정확하고 문항도 아낀다.
